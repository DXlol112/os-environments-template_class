# Postmortem · учебный сервер diag-lab

## Симптом

В 10:18 сайт отвечал за 353–847 мс, load average — 4,45 / 2,18 / 2,45.

## Причина

report-builder запустил 16 процессов report-calc, которые нагружали CPU. sync-agent завис с блокировкой sync.lock и не завершался по TERM.

## Действия

Для report-calc установлен nice 19: ответ снизился до 207–263 мс. report-builder остановлен через TERM, оставшиеся расчёты — через KILL; ответ снизился до 139 мс. sync-agent завершён через KILL после безрезультатного TERM, sync.lock удалён. В exit-codes.log: report-builder — сигнал 15, sync-agent — сигнал 9.

## Профилактика

Запускать расчёты с nice 19, ограничить их число количеством ядер. При TERM завершать дочерние расчёты, а в sync-agent добавить удаление sync.lock при выходе.

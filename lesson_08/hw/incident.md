# Postmortem · нагрузка CPU

## Симптом

До запуска load average — 1,68 / 1,93 / 2,47, во время — 1,96 / 1,99 / 2,48. В `top` появился bash с загрузкой 99% CPU — почти одно логическое ядро.

## Причина

Запущен бесконечный цикл `bash -c 'while :; do :; done'`, закреплённый за CPU 0 через taskset. В песочнице его PID — 7, родитель — Python (PID 2), рабочий каталог — /tmp.

## Действия

Сняты `uptime`, `free -h` и `top -b -n 2 -d 1`. Виновник найден через `ps --sort=-pcpu`, `pstree -s -p 7` и `readlink /proc/7/cwd`. После `kill -TERM 7` процесс завершился сигналом 15 и исчез из повторного top. Load average сразу осталась прежней: это среднее за интервал.

```bash
/usr/bin/time -f "%e s, %M KB" python3 -c 'a = bytearray(64 * 1024 * 1024)'
# 0.05 s, 74652 KB
```

Время 0,05 с включает запуск Python, выделение и освобождение массива. Пик — около 72,9 МиБ: массив занимает 64 МиБ, остальное — интерпретатор и служебные данные; `%M` измеряется в КиБ.

## Профилактика

Добавлять условие выхода из циклов. Фоновые расчёты запускать с `nice -n 19`, длительность ограничивать через `timeout 30s`.

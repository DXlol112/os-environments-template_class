# Журнал команд · практическая работа №3

В журнал записывается каждая команда, которая изменила файлы или помогла найти ответ.
Безопасный пример — вариант команды, который сначала показывает результат и ничего не удаляет.

| №   | Команда                                                              | Что сделала                                                                     | Безопасный пример                                                                         |
| --- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| 1   | `mkdir -p ../sorted/{docs,images,logs,data}`                         | создала четыре каталога                                                         | `mkdir -pv …` — печатает созданные каталоги                                               |
| 2   | `ls *.bak`                                                           | показала, какие файлы попадут под маску                                         | —                                                                                         |
| 3   | `rm -v *.bak`                                                        | удалила резервные копии                                                         | `rm -i *.bak` — спрашивает про каждый файл                                                |
| 4   | `ls report-2026-0?.txt`                                              | показала отчёты за месяцы 01, 02 и 03 (в inbox)                                 | та же команда — только показывает имена                                                   |
| 5   | `ls photo-00[1-3].jpg`                                               | показала фотографии 001, 002 и 003 (в inbox)                                    | та же команда — только показывает имена                                                   |
| 6   | `ls *.{jpg,png}`                                                     | показала все JPG- и PNG-файлы (в inbox)                                         | та же команда — только показывает имена                                                   |
| 7   | `echo app.log*`                                                      | показала имена основного журнала и его ротаций (в inbox)                        | та же команда — только выводит имена                                                      |
| 8   | `echo .*`                                                            | показала имена скрытых файлов (в inbox)                                         | та же команда — только выводит имена                                                      |
| 9   | `echo *`                                                             | показала имена файлов и каталогов без скрытых (в inbox)                         | та же команда — только выводит имена                                                      |
| 10  | `mv -v "my report.txt" my-report.txt`                                | переименовала файл, убрав пробел (в inbox)                                      | `ls -l "my report.txt"` — проверить исходный файл                                         |
| 11  | `mv report-*.txt my-report.txt ~/files-lab/sorted/docs/`             | переместила семь документов в sorted/docs (из inbox)                            | `ls report-*.txt my-report.txt` — проверить список документов                             |
| 12  | `mv *.{jpg,png} ~/files-lab/sorted/images`                           | переместила шесть изображений в sorted/images (из inbox)                        | `ls *.{jpg,png}` — проверить список изображений                                           |
| 13  | `mv {app.log*,error.log} ~/files-lab/sorted/logs`                    | переместила четыре журнала в sorted/logs (из inbox)                             | `ls app.log* error.log` — проверить список журналов                                       |
| 14  | `cp *csv ~/files-lab/sorted/data`                                    | скопировала два CSV-файла в sorted/data, сохранив оригиналы (из inbox)          | `ls *csv` — проверить список CSV-файлов                                                   |
| 15  | `ls ~/files-lab/sorted/data`                                         | проверила содержимое каталога с копиями CSV                                     | та же команда — только показывает имена                                                   |
| 16  | `find ~/files-lab -type f -size +1M -exec ls -lh {} \; -ok rm {} \;` | нашла файл больше 1 МиБ, показала его размер и запросила подтверждение удаления | `find ~/files-lab -type f -size +1M -exec ls -lh {} \;` — только показать найденные файлы |
| 17  | `find -type f -mtime +30 > ~/files-lab/answers.txt`                  | записала пути к файлам старше 30 дней в ответы (поиск из inbox)                 | `find . -type f -mtime +30` — вывести результат без перезаписи файла                      |
| 18  | `ls -A`                                                              | показала содержимое inbox, включая скрытый файл .settings                       | та же команда — только показывает имена                                                   |
| 19  | `cat .settings >> ~/files-lab/answers.txt`                           | добавила значение token из .settings в ответы (из inbox)                        | `cat .settings` — вывести содержимое без записи в answers.txt                             |
| 20  | `man ls`                                                             | открыла справку ls для поиска ключа сортировки по размеру                       | та же команда — только открывает справку                                                  |
| 21  | `echo "ls -lS sorted/images" >> ~/files-lab/answers.txt`             | добавила команду сортировки изображений по размеру в ответы                     | `echo "ls -l -S sorted/images"` — показать команду без записи в файл                      |
| 22  | `tree ~/files-lab/sorted`                                            | показала структуру каталогов с рассортированными файлами                        | та же команда — только показывает структуру                                               |
| 23  | `locate os-release \| head -1 >> ~/files-lab/answers.txt`            | добавила первый найденный путь к os-release в ответы                            | `locate os-release` — вывести найденные пути без записи в файл                            |

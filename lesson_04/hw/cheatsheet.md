# Шпаргалка команд



| Команда                | Назначение                           | Безопасный пример                                                                    | Опасный вариант и чем он опасен                                                |
| ---------------------- | ------------------------------------ | ------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------ |
| `mkdir -p`             | создаёт каталоги и весь путь         | `mkdir -p site/css site/img backup`                                                  | `mkdir my folder` — создаст два каталога вместо одного                         |
| `touch`                | создаёт файл или обновляет его время | `touch site/index.html`                                                              | `touch inbox/data.csv` — изменит время существующего файла                     |
| `ls`                   | показывает содержимое каталога       | `ls -A inbox`                                                                        | `ls inbox` — скрытые файлы не видны                                            |
| `tree`                 | показывает дерево каталогов          | `tree site`                                                                          | Нет: только показывает структуру                                               |
| `cp`                   | копирует файлы                       | `cp -i inbox/data.csv backup/`                                                       | `cp inbox/data.csv backup/` — перезапишет копию без вопроса                    |
| `mv`                   | перемещает и переименовывает         | `mv -i "inbox/my report.txt" inbox/my-report.txt`                                    | `mv inbox/todo.md inbox/notes.md` — перезапишет существующий файл              |
| `ln -s`                | создаёт символическую ссылку         | `ln -s inbox/report-final.txt latest-report.txt`                                     | `ln -s report-final.txt latest-report.txt` — неверный путь, ссылка не работает |
| `rm`                   | удаляет файлы без корзины            | `ls inbox/*.bak`, затем `rm -i inbox/*.bak`                                          | `rm inbox/* .bak` — лишний пробел, удалит все обычные файлы в `inbox`          |
| `rmdir`                | удаляет пустой каталог               | `rmdir site/img`                                                                     | Замена на `rm -r site/img` — удалит и непустой каталог                         |
| `ls photo-00[1-3].jpg` | выбирает символ из диапазона         | `ls inbox/photo-00[1-3].jpg`                                                         | `rm inbox/photo-00[1-3].jpg` — удалит выбранные фото                           |
| `find -name`           | ищет файлы по имени                  | `find . -type f -name "*.csv"`                                                       | `find . -name *.csv` — без кавычек маску обрабатывает оболочка                 |
| `find -delete`         | удаляет найденные файлы              | `find inbox -type f -name "*.bak"`, затем `find inbox -type f -name "*.bak" -delete` | `find inbox -delete -name "*.bak"` — удаление до проверки имени                |
| `locate`               | ищет пути по базе                    | `locate -e os-release`                                                               | `locate os-release` — может показать уже удалённые файлы                       |
| `man`                  | открывает справку команды            | `man ls`                                                                             | Нет: только читает справку                                                     |
| `man -k`               | ищет команды по описанию             | `man -k "copy files"`                                                                | Нет: только ищет в справке                                                     |
